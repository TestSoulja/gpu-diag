# Changelog

Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — SemVer.

## [1.4] — 2026-11-23

### Добавлено
- `ACTION-RU.txt` на Рабочем столе и внутри ZIP: разбор простыми словами по-русски —
  главная причина, находки по важности, шаги по порядку, что уже исправлено автоматически,
  что отправить обратно. Русский текст и действие есть для всех 35 находок, неизвестная
  находка печатается как «см. report.txt», а не выдумывается.
- Логгер запускается из стабильной копии `%LOCALAPPDATA%\GPU-Diag\engine\GPU-Diag.ps1`:
  переживает перезагрузку, перенос и замену распакованной папки; откат на более старую
  версию движка запрещён.
- Задача планировщика перезапускает логгер до 3 раз с интервалом 1 минута при падении.
- После установки записи инструмент проверяет её состояние и сообщает: «включена»,
  «только на эту сессию» или «не включилась».

### Изменено
- Пункт `1` больше не задаёт вопросов и не предлагает перезагрузку: отчёт, безопасные
  правки и фоновая запись делаются за один проход. `TdrDelay` применится при следующей
  обычной перезагрузке, специально перезагружаться не нужно.
- Меню двуязычное, сверху подсказка «нажми 1 и Enter».
- `ACTION-RU.txt` и итоговый экран объясняют, что запись после перезагрузки включится сама.

## [1.3] — 2026-11-23

### Исправлено
- Подсказка после включения фоновой записи отправляла в пункт `3` вместо `4`
  («стоп + финальный ZIP») — теперь называется правильный пункт.
- Текст в `FINDINGS` при пустом результате советовал «menu 2» для фоновой записи;
  правильный пункт — `3`.
- В инструкции для владельца ПК (`src/README-RU.txt`) в списке правок не хватало
  USB selective suspend; порядок приведён к фактическому списку меню `5`.

## [1.2] — 2026-11-23

### Добавлено
- Раздел отчёта `CPU / THERMAL CHECK`: загрузка и частота CPU, % от максимума,
  температура через ACPI, события `Microsoft-Windows-Kernel-Processor-Power` id 37
  («скорость ограничена прошивкой»).
- Файл `thermal.csv` в фоновой записи — температура и частота CPU каждые 5 секунд.
- Контекст CPU в `events.log` рядом с контекстом GPU.
- Режим `-Mode SelfTest`: применяет и откатывает правки, проверяет планировщик,
  экспорт журнала и упаковку ZIP, печатает `RESULT: PASS|FAIL`.
- `build.ps1` для сборки архива `dist\GPU-Diag-for-friend.zip`.

### Исправлено
- Повторное включение логгера больше не оставляет два процесса: старый останавливается.
- `Clear-Host` не роняет меню при перенаправленном выводе.
- В архив не попадает служебный `stop.flag`.

## [1.1] — 2026-11-23

### Добавлено
- Пункт меню `1` — «DO EVERYTHING»: отчёт + правки + фоновая запись за один проход.
- Раздел `DRIVER HEALTH CHECK`: подпись драйверов, остатки пакетов в DriverStore,
  незавершённая установка, поиск обновлений драйверов в Windows Update (с лимитом 60 с).
- Настройки питания задаются по GUID, а не по локализованным алиасам `powercfg`.

### Изменено
- Нумерация меню: `1..6` вместо `1..5`.
- Отчёт: меньше шума в журнале событий (только релевантные провайдеры), WER-сигнатуры
  группируются по коду `P1`, ошибки видеоустройств выделяются отдельно от прочих.

## [1.0] — 2026-11-23

### Добавлено
- Первый рабочий выпуск: отчёт по GPU/драйверам/мониторам, журналы событий, дампы,
  настройки питания и реестра графики, нагрузка GPU по процессам, `nvidia-smi`.
- Безопасные обратимые правки (ASPM, USB suspend, таймер экрана, Fast Startup, TDR)
  с бэкапом и откатом.
- Фоновая запись через планировщик: `gpu-watch.csv`, `events.log`.
- Упаковка отчёта и логов в ZIP на рабочем столе.
