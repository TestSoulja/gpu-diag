# GPU Diag — диагностика «монитор время от времени отключается»

Набор скриптов для Windows 10/11, который помогает найти причину внезапного пропадания
изображения (чёрный экран / «нет сигнала») на компьютере, где видеокарта в этот момент
под нагрузкой.

Инструмент ничего не устанавливает, ничего не отправляет в интернет и не удаляет файлы.
Он собирает отчёт, ведёт фоновую запись телеметрии и может применить несколько безопасных
обратимых изменений в настройках питания.

```
src/
  START-HERE.bat     запуск (двойной клик)
  GPU-Diag.ps1       сам инструмент
  README-RU.txt      инструкция для человека, который запускает (на русском)
```

## Быстрый старт (для владельца компьютера)

1. Распаковать `GPU-Diag-for-friend.zip` в папку (не запускать изнутри архива).
2. Двойной клик по `START-HERE.bat` → «Да» в UAC.
3. В меню выбрать `1` (DO EVERYTHING). Больше ничего нажимать не нужно: отчёт,
   безопасные правки и фоновая запись делаются за один проход, перезагрузка не требуется.
4. На рабочем столе появятся `ACTION-RU.txt` (что найдено и что делать по-русски)
   и ZIP-архив для отправки.
5. Пользоваться компьютером как обычно. Запись после перезагрузки запускается сама.
6. Когда проблема повторится — запустить снова, выбрать `4`, отправить свежий ZIP.

Подробная инструкция на русском: [`src/README-RU.txt`](src/README-RU.txt).

## Меню

| Пункт | Что делает |
|---|---|
| `1` | **DO EVERYTHING** — отчёт + безопасные правки + фоновая запись, без вопросов и без перезагрузки |
| `2` | только отчёт (read-only, ~15–60 с) |
| `3` | включить фоновую запись (перерегистрирует задачу, если уже работает) |
| `4` | остановить запись + собрать финальный ZIP |
| `5` | только безопасные правки |
| `6` | отменить безопасные правки (по сохранённому бэкапу) |
| `0` | выход |

Пункты `1`, `2` и `4` кладут на рабочий стол `ACTION-RU.txt` — тот же вывод, что и
`FINDINGS`, но простыми словами по-русски: что найдено, что делать по порядку, что уже
сделано автоматически и что отправить обратно. Файл также попадает внутрь ZIP.

## Что проверяется

- Видеокарты: модель, драйвер, версия/дата, текущий режим и герцовка.
- **Драйверы**: цифровая подпись, остатки старых версий в DriverStore, незавершённая
  установка (pending reboot), поиск обновлений драйверов в Windows Update (только чтение).
- Мониторы: модель, год выпуска, **тип физического подключения** (HDMI / DisplayPort / DVI).
- Устройства с ошибками в диспетчере устройств (с разделением «видео» и «прочее»).
- Живая нагрузка GPU по процессам; подозрительные процессы из `%TEMP%` и майнеры по именам.
- NVIDIA live-данные через `nvidia-smi`: температура, потребление, частоты, троттлинг,
  режим линии PCIe (`gen`/`x`), retired pages.
- **CPU**: загрузка, частота в % от максимума, события «скорость ограничена прошивкой» (id 37),
  температура через ACPI, если плата её отдаёт.
- Питание: PCIe ASPM, таймеры экрана/сна, USB selective suspend, «Быстрый запуск».
- Реестр графики: `TdrDelay`, `TdrDdiDelay`, `TdrLevel`, `HwSchMode` (HAGS),
  `OverlayTestMode` (MPO-оверлей).
- Связка «сбой экрана ↔ установка драйвера»: дата первой ошибки против даты самого свежего
  пакета GPU-драйвера; подсказки по HAGS, MPO и герцовке — только текст, ничего не меняется.
- Журнал System за 30 дней: TDR (4101/4102/4103), WHEA (17/18/19), Kernel-Power 41,
  BugCheck/1001, EventLog 6008, Kernel-PnP (219/411/442).
- Дампы: `C:\Windows\Minidump`, `C:\Windows\LiveKernelReports` (WATCHDOG = 0x141).
- WER-сигнатуры `LiveKernelEvent` / `BlueScreen` с группировкой по `P1` (141/117 = зависание
  видеодвижка).
- ПО разгона и оверлеи, автозагрузка.

В конце отчёта — раздел `FINDINGS` с приоритетами: HIGH / MEDIUM / LOW / INFO.

## Что меняют «безопасные правки»

| Что | Было → стало |
|---|---|
| PCIe link power saving (ASPM) | On → **Off** (AC и DC) |
| USB selective suspend | On → Disabled |
| Отключение экрана по таймеру (AC) | N мин → **Never** |
| Fast Startup (`HiberbootEnabled`) | 1 → **0** |
| `TdrDelay` / `TdrDdiDelay` | 2 / 5 → **10 / 5** |

Все исходные значения сохраняются в `%LOCALAPPDATA%\GPU-Diag\fix-backup.json`,
пункт меню `6` возвращает их обратно. Перезагрузка не запрашивается: ASPM, USB и таймер
экрана действуют сразу, Fast Startup — с ближайшего выключения, `TdrDelay` — с ближайшей
перезагрузки (когда она случится сама).

## Фоновая запись

Регистрируется задача планировщика `GPU-Diag-Watch` (запуск при входе в систему,
`RunLevel Highest`, без ограничения времени выполнения, до 3 перезапусков при падении).
Логгер запускается из стабильной копии `%LOCALAPPDATA%\GPU-Diag\engine\GPU-Diag.ps1`,
поэтому переживает перезагрузку, перенос и переустановку распакованной папки; версия
движка не откатывается на более старую. Логи в `%LOCALAPPDATA%\GPU-Diag`:

| Файл | Содержимое |
|---|---|
| `gpu-watch.csv` | каждые 5 с: температура/загрузка/память/питание/частоты/троттлинг GPU, режим линии PCIe (`gen`/`width`), число активных мониторов, заголовок активного окна |
| `thermal.csv` | каждые 5 с: температура и частота CPU, % от максимума |
| `events.log` | только релевантные события System + контекст GPU/CPU/PCIe в этот момент |
| `state.json` | последний обработанный RecordId |
| `watch-errors.log` | ошибки самого логгера |
| `gpu-watch-<таймстамп>.csv` | старый лог после смены формата колонок (не удаляется) |

Логи не ротируются автоматически — при многодневной записи следите за размером
(`gpu-watch.csv` ≈ 2–3 МБ в сутки).

## Приватность

Скрипт не делает сетевых запросов. Единственное исключение — поиск обновлений драйверов
через локальную службу Windows Update (запрос делает сама Windows).

**Важно:** в `gpu-watch.csv` пишется заголовок активного окна — там могут быть названия
сайтов и чатов. Перед отправкой архива третьим лицам файл стоит просмотреть.

## Сборка архива для отправки

```powershell
.\build.ps1
```

Создаёт `dist\GPU-Diag-for-friend.zip` (внутри папка `GPU-Diag` с тремя файлами).
Архив в `.gitignore` — в репозиторий не попадает.

## Требования и ограничения

- Windows 10/11, Windows PowerShell 5.1 (встроенный). Администратор — для правок,
  журналов и планировщика; отчёт собирается и без прав.
- `nvidia-smi`-блок только для NVIDIA. Для AMD/Intel отчёт всё равно работает,
  но без live-телеметрии GPU.
- Температура CPU видна только если материнская плата отдаёт ACPI thermal zone
  (на многих десктопах — нет). Реальные температуры ядер — HWiNFO / BIOS.
- Поиск в Windows Update ограничен 60 секундами; при выключенной службе просто
  пропускается.

## Самопроверка

```powershell
powershell -ExecutionPolicy Bypass -File .\src\GPU-Diag.ps1 -Mode SelfTest
```

Под администратором применяет и откатывает все правки, проверяет регистрацию задачи,
экспорт журнала и упаковку ZIP. Пишет `selftest.log` рядом со скриптом и печатает
`RESULT: PASS|FAIL`.
