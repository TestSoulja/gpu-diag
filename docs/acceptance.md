## Не проверялось

Ниже — не «работает», а именно отсутствие прогона.

- **Windows 10** — машина на Windows 11 (build 26300). На Windows 10 инструмент
  не запускался.
- **AMD GPU без `nvidia-smi`** — машины с AMD не было.
- **Только Intel без `nvidia-smi`** — Intel UHD 770 в машине есть, но `nvidia-smi`
  тоже есть, поэтому чистого прогона «Intel без NVIDIA» не было.
- **Вторая машина** — все прогоны на одной машине (DESKTOP-GP6OJ4U).
- **Реальный сбой экрана в момент записи** — за 6 ч записи 26.11.2026 в `events.log`
  только «logger started/stopped»; сбоя во время записи не было. Прошлые сбои
  (2026-11-21) видны только как записи журнала.
- **Удаление папки при живой задаче** — не воспроизводилось.
- **`-Mode SelfTest`** — не запускался: `selftest.log` рядом со скриптом отсутствует,
  прогон требует прав администратора и меняет настройки.
- **Откат правок пунктом 6** — не запускался; наличие `fix-backup.json` подтверждено,
  возврат значений — нет.
- **Архив с дампами** — в `C:\Windows\Minidump` на этой машине 0 файлов `*.dmp`,
  поэтому копирование дампов в ZIP не проверялось. `live-kernel-reports.txt` —
  только список файлов, сами дампы `LiveKernelReports` в архив не копируются.
