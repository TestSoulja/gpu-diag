# Бэклог

Долги с причиной и порядком. Сроков нет; порядок — сверху вниз.

1. **Машинный страж не запускается автоматически.** `check.ps1` есть и проходит на
   чистом дереве, но его запускает человек. Причина: без автозапуска забытая правка
   `src` без версии и CHANGELOG обнаружится только при следующем релизе. Автозапуск
   (CI) — только по «да» владельца; сторонние сервисы не предлагать.

2. **Ротация логов не сделана.** `gpu-watch.csv` ≈ 2–3 МБ в сутки и растёт без
   ограничения (`README.md`, раздел «Фоновая запись»); старый файл только
   переименовывается при смене формата колонок. Причина: многодневная запись занимает
   диск и увеличивает финальный ZIP. Правка `src/**` → новая версия, CHANGELOG, архив.

3. **Дампы в ZIP и их приватность.** В архив копируются до пяти `*.dmp` из
   `C:\Windows\Minidump` (папка `minidumps\`) — это фрагменты памяти.
   `live-kernel-reports.txt` содержит только список файлов `LiveKernelReports`, сами
   дампы оттуда не копируются. Причина: приватность и размер архива. Решение
   (оставлять, ограничивать, предупреждать) — за владельцем; правка `src/**` → 1.5.5+.

4. **Формулировка в `src/README-RU.txt`.** Строка 103: «в Windows Update (только
   сообщает, ничего не устанавливает)» — про поиск обновлений драйверов это верно
   (инструмент сам ничего не устанавливает), но при буквальном поиске фразы она
   читается как прежнее общее утверждение. Причина: публичный текст должен быть
   однозначным. Это `src/**` → правка только в версии 1.5.5+ (в этом шаге `src` не
   менялся).

5. **AMD/Intel без `nvidia-smi`.** В README написано, что отчёт работает без
   live-телеметрии GPU, но на такой машине прогонов не было. Причина: неизвестно,
   не ломается ли отчёт на путях без `nvidia-smi`. Нужна машина и прогон; правок
   `src` это не требует, пока не найден дефект.

6. **CX/CI не решён.** Автоматическая проверка при push не настроена; GitHub Actions
   возможен только после «да» владельца. Сторонние сервисы (мониторинг, облака,
   панели) не предлагать — правило владельца от 24.11.2026.

7. **Что дальше по продукту** — списком, без обещаний:
   - прогон `-Mode SelfTest` под администратором (сейчас не проверялся);
   - откат правок пунктом 6 на живой машине;
   - реальный сбой экрана во время записи;
   - вторая машина;
   - удаление папки при живой задаче;
   - тексты `src/README-RU.txt` и состав ZIP после решения по ротации и дампам
     (правка `src` → 1.5.5+).
