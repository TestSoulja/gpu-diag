# Бэклог

Долги с причиной и порядком. Сроков нет; порядок — сверху вниз.

1. **Проверки не запускаются автоматически.** `check.ps1` и `tests\run.ps1` есть и
   проходят на чистом дереве, но их запускает человек. Причина: без автозапуска
   забытая правка `src` без версии и CHANGELOG обнаружится только при следующем
   релизе. Автозапуск (CI) — только по «да» владельца; сторонние сервисы не
   предлагать. Тесты покрывают чистые функции и тексты, но `Build-Report` целиком
   не тестируется без инъекции данных: иначе тест проверял бы конкретную машину,
   журналы и железо, а не код.

2. **Ротация логов не сделана.** `gpu-watch.csv` ≈ 2–3 МБ в сутки и растёт без
   ограничения (`README.md`, раздел «Фоновая запись»); старый файл только
   переименовывается при смене формата колонок. Причина: многодневная запись занимает
   диск и увеличивает финальный ZIP. Правка `src/**` → новая версия, CHANGELOG, архив.

3. **Дампы в ZIP и их приватность.** В архив копируются до пяти `*.dmp` из
   `C:\Windows\Minidump` (папка `minidumps\`), не больше 100 МБ суммарно — это
   фрагменты памяти. `live-kernel-reports.txt` содержит только список файлов
   `LiveKernelReports`, сами дампы оттуда не копируются. Ограничение и описание в
   инструкции добавлены в 1.5.5; остаётся вопрос, копировать ли дампы вообще.
   Решение — за владельцем; правка `src/**` → новая версия, CHANGELOG, архив.

4. **AMD/Intel без `nvidia-smi`.** В README написано, что отчёт работает без
   live-телеметрии GPU, но на такой машине прогонов не было. Причина: неизвестно,
   не ломается ли отчёт на путях без `nvidia-smi`. Нужна машина и прогон; правок
   `src` это не требует, пока не найден дефект.

5. **Что дальше по продукту** — списком, без обещаний:
   - прогон `-Mode SelfTest` под администратором (сейчас не проверялся);
   - откат правок пунктом 6 на живой машине;
   - реальный сбой экрана во время записи;
   - вторая машина;
   - удаление папки при живой задаче.
